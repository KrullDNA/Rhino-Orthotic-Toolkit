# Grasshopper-ի Սկսնակներու Ուղեցոյց — Ուղղագործական Ներբան

Grasshopper-ի փորձ չի՛ պահանջեր։ Քայլերը հետեւէ՛ կարգով։ Առաջին
անգամուան համար մօտաւորապէս 20–30 վայրկեան կը պահանջէ։ Անկէ ետք
ֆայլը բանալ եւ սահեցուցիչներով խաղալ՝ քանի մը երկվայրկեանի գործ է։

> **Նշում.** Բոլոր *Grasshopper*, *Rhino*, *Brep*, *SubD*, *Python*,
> *GhPython* բառերը՝ ինչպէս կան, լատինատառ պահուած են։ Միայն
> հրահանգները՝ արեւմտահայերէն։

---

## 0. Ի՞նչ է Grasshopper-ը

Grasshopper-ը տեսողական ծրագրաւորման տարածք մըն է որ կ՚ապրի
**Rhino-ին մէջ**։ Կը գցես «բաղադրիչներ» (տուփեր) ու անոնց ելքերը կը
կապես ուրիշ բաղադրիչներու մուտքերուն՝ լարերով։ Երբ արժէք մը
կը փոխես՝ ամէն ինչ ինքնաշխատ կերպով կը նորոգուի։ Այս ապրող
թարմացումը ճիշդ ա՛յն է որ կ՚ուզենք ներբանին համար։

Դուն ոչ մէկ ծրագիր (code) պիտի գրես։ Արդէն գրուած Python ծրագիրը
պիտի **փակցնես** «Python 3 Script» անունով յատուկ բաղադրիչի մը մէջ։

---

## 1. Բացի՛ր Grasshopper-ը

1. Բացի՛ր **Rhino 8**-ը։
2. Rhino-ի հրահանգագիծին մէջ գրէ՛ `Grasshopper` եւ սեղմէ՛ Enter։
3. Երկրորդ պատուհան մը կը բացուի — ատիկա Grasshopper-ի կտաւն է։
   Երկու պատուհանները կողք-կողքի տեսանելի պահէ՛։

Grasshopper-ի կտաւը ունի՝
- վերի կողմը՝ **ժապաւէն** մը՝ ներդիրներով (Params, Maths, Sets,
  Vector, Curve, Surface, Mesh, Intersect, Transform, Display,
  **Script**),
- անոր տակ՝ սպիտակ կտաւ։

---

## 2. Անդրադարձուր կոշիկի կաղապարդ Rhino-էն

Կոշիկի կաղապարդ արդէն Rhino-ի փաստաթուղթին մէջ է։ Հարկ է զայն
Grasshopper-ին «անդրադարձնել»։

1. Rhino-ին մէջ բացի՛ր **այն ֆայլը որ ունի կոշիկի կաղապարը**
   (բազմամակերես կամ SubD)։
2. Grasshopper-ին մէջ գնա՛ **Params** ներդիրը → **Geometry**
   խումբը → քաշէ՛ **Brep** պարամետր մը կտաւին վրայ։ (Դատարկ
   մոխրագոյն վեցանկիւն մը՝ `Brep` պիտակով։)
3. **Աջ-սեղմէ՛** Brep պարամետրին վրայ → **Set one Brep**։
4. Grasshopper կը պահուի, Rhino կ՚ակտիվանայ։ Կտտացնէ՛ կաղապարդ։
5. Կտաւին վրայ գտնուող Brep պարամետրը մոխրագոյնէ կը փոխուի՝
   ցուցադրելու համար որ կաղապարը կապուած է։

> Եթէ կաղապարդ **SubD** է, Params → Geometry խումբէն գցէ՛ `SubD`
> պարամետր մը, յետոյ իբրեւ կամուրջ տեղադրէ՛ **SubD to Brep**
> բաղադրիչ մը (Surface → SubD → SubD to Brep)։ Մէկ անգամ
> վերածէ՛ — ամէն նիստի մէջ չի՛ կրկնուիր։

---

## 3. Գցէ՛ Python Script բաղադրիչը

1. Կտաւին **սպիտակ տեղ մը կրկնակի սեղմէ՛**։ Որոնման տուփ կը բացուի։
2. Գրէ՛ `python 3` եւ ընտրէ՛ **Python 3 Script** (կանաչ-ծիրանի
   պատկերակով, որուն մօտ կը գրէ "CPython 3")։ Սեղմէ՛ Enter։
3. Փոքր բաղադրիչ մը կը յայտնուի՝ լռելեան `x` եւ `y` մուտքերով ու
   `a` ելքով։

Այս բաղադրիչին մէջ պիտի դնենք ներբանի ծրագիրը։

## 4. Կարգաւորէ՛ բաղադրիչին մուտքերը

Միաբաղադրիչ ծրագիրը 11 մուտք կ՚ուզէ։ Մէկ-մէկ պիտի աւելցնենք։

### 4ա. Բացի՛ր ծրագիր-խմբագիրը

**Կրկնակի սեղմէ՛** `Python 3 Script` բաղադրիչը։ Խմբագիրը կը բացուի։

### 4բ. Փոխարինէ՛ լռելեան ծրագիրը

1. Խմբագիրին մէջ ընտրէ՛ ամէն բան (Ctrl+A) ու ջնջէ՛։
2. Որեւէ խմբագիրով բացի՛ր
   `Grasshopper/components/00_orthotic_insole_all_in_one.py`
   ֆայլը այս պահեստէն (repository)։
3. Պատճենէ՛ **բոլոր բովանդակութիւնը** ու փակցուր GH խմբագիրին մէջ։
4. Կտտացուր **Test** (խմբագիրի վարը) — սխալներ պիտի տեսնես՝ ինչպէս
   «`Last` չէ սահմանուած» եւ «`PerimeterOffset`»-ի մասին։ Բնական է —
   տակաւին մուտքերը չենք ստեղծած։ Փակէ՛ սխալի պատուհանը։
5. Փակէ՛ խմբագիրը (X)։ Բաղադրիչը հիմա կտաւին վրայ է՝ փակցուած ծրագիրով։

### 4գ. Աւելցո՛ւր մուտքերը

Բաղադրիչը կը սկսի երկու մուտքով (`x`, `y`)։ Մեզի 11 պէտք է։

**Մուտք մը վերանուանելու համար.**
- **Աջ-սեղմէ՛ մուտքի անունին վրայ** (օրինակ՝ ձախի կողմը՝ `x`) →
  ընտրէ՛ **«x»** վերը → տեքստի դաշտ կը բացուի → գրէ՛ նոր անունը →
  Enter։

**Աւելի մուտք աւելցնելու համար.**
- **Մօտեցուր** (zoom in) բաղադրիչին՝ մինչեւ տեսնես փոքր `+` եւ
  `−` պատկերակները մուտքերուն կողքին։ `+` սեղմէ՛ նոր մուտք մը
  աւելցնելու համար։
- (Կամ՝ աջ-սեղմէ՛ բաղադրիչին գլխագիրը → **Add Input**։)

Վերանուանէ՛ ու աւելցո՛ւր մինչեւ որ ունենաս հետեւեալ 11 մուտքերը՝
վերէն վար.

| Մուտքի անունը     | Type hint        | Access |
|-------------------|------------------|--------|
| `Last`            | Brep             | Item   |
| `PerimeterOffset` | float / Number   | Item   |
| `ToeExtension`    | float / Number   | Item   |
| `HeelExtension`   | float / Number   | Item   |
| `CoverThk`        | float / Number   | Item   |
| `ShellThk`        | float / Number   | Item   |
| `BaseThk`         | float / Number   | Item   |
| `OverrideOutline` | Curve            | Item   |
| `OverrideBottom`  | Curve            | Item   |
| `MaxEdge`         | float / Number   | Item   |
| `MinEdge`         | float / Number   | Item   |

(`RebuildCount` պարտադիր չէ։ Ուզելու պարագային՝ աւելցո՛ւր։)

**Type hint դնելու համար.**
- Աջ-սեղմէ՛ մուտքին անունը → **Type hint** → ընտրէ՛ ցանկէն։
- `Last` / `OverrideOutline` / `OverrideBottom`-ի համար՝ **Brep**,
  **Curve**, **Curve**։
- Թիւերուն համար՝ **float**։

**Access դնելու համար.**
- Աջ-սեղմէ՛ մուտքին անունը → **Access** → **Item Access**։

### 4դ. Աւելցո՛ւր ելքերը

Լռելեան ելքը `a`-ն է։ Մեզի 8 պէտք է — նոյն ընթացքով, աջ կողմը.

| Ելքի անունը |
|-------------|
| `SubD`      |
| `Mesh`      |
| `Footprint` |
| `Outline`   |
| `TopEdge`   |
| `BottomEdge`|
| `Axis`      |
| `ToeDir`    |

Ելքերուն type hint պէտք չէ՛ դնել — Grasshopper ինք կը հասկնայ։

## 5. Կապէ՛ կաղապարը մուտքին

1. Քաշէ՛ լար մը անդրադարձուած կաղապարին **Brep** պարամետրէն
   (աջի կլոր) մինչեւ ծրագիրի բաղադրիչին **Last** մուտքը (ձախի կլոր)։
2. Բաղադրիչը հիմա կաղապարը կրնայ տեսնել։ Վրան մնալով (hover)՝
   պիտի ըսէ "Last: 1 Brep"։

Եթէ բաղադրիչին եզրը **կարմիր** է, վրան մնա՛ — Grasshopper կը
բացատրէ ինչը կը պակսի։ Ամէնէն հաւանականը՝ "PerimeterOffset is None",
որովհետեւ սահեցուցիչներ տակաւին չենք կապած։ Շարունակէ՛։

## 6. Աւելցո՛ւր թիւային սահեցուցիչներ (number sliders)

Ամէնօրեայ պարամետրերուն համար 6 սահեցուցիչ պէտք են։

1. **Կրկնակի սեղմէ՛ կտաւին** → գրէ՛ `2..0..10` ու Enter։
   - Ասիկա հապաւում է՝ **լռելեան=2, նուազագոյն=0, առաւելագոյն=10**։
     Սահեցուցիչը կտաւին վրայ կը հայտնուի՝ արդէն կարգաւորուած։
2. **Աջ-սեղմէ՛ սահեցուցիչին** → **Edit** → **Name**-ը փոխէ՛
   `PerimeterOffset` (շատ սահեցուցիչներ ունենալու պարագային՝ կ՚օգնէ)։
3. Քաշէ՛ լար մը սահեցուցիչին աջէն մինչեւ ծրագիրի `PerimeterOffset`-ը։

Կրկնէ՛ ամէն սահեցուցիչին համար.

| Սահեցուցիչի անունը | Հապաւում          | Լռելեան |
|-------------------|--------------------|---------|
| PerimeterOffset   | `2..0..10`         | 2.0 մմ  |
| ToeExtension      | `0..-10..30`       | 0.0 մմ  |
| HeelExtension     | `0..-10..30`       | 0.0 մմ  |
| CoverThk          | `2..0.5..10`       | 2.0 մմ  |
| ShellThk          | `3..0.5..15`       | 3.0 մմ  |
| BaseThk           | `5..0.5..20`       | 5.0 մմ  |

`MaxEdge` եւ `MinEdge`-ը անկապ ձգէ՛ — ծրագիրը ինք կ՚օգտագործէ
լռելեան արժէքները (3.0 ու 1.0)։

## 7. Տեսանելի դարձնէ՛ SubD-ն

1. Աջի **SubD** ելքն է որ պիտի տեսնենք։
2. Կտաւին վրայ որոնէ՛ **SubD** → գցէ՛ `SubD` պարամետր մը։
3. Կապէ՛ ծրագիրի `SubD` ելքը → SubD պարամետրի մուտքը։
4. SubD պարամետրը ունի փոքր պատկերակ՝ որ ցոյց կու տայ թէ նախադիտումը
   բացուած է։ Եթէ չէ՝ աջ-սեղմէ՛ → **Preview**։
5. Rhino-ի դիտատախտակին նայէ՛ — ներբանը կաղապարին վրայ պիտի երեւի՝
   կապոյտ SubD ձեւով։

Եթէ ոչինչ կ՚երեւի.
- Ստուգէ՛ որ ծրագիրի բաղադրիչը կարմիր չէ։ Hover ընելով սխալը կարդա՛։
- Համոզուէ՛ որ Brep պարամետրը ճիշդ անդրադարձուած է։
- Համոզուէ՛ որ կաղապարդ ներբան-վար (sole-down, −Z ուղղութեամբ) է։

## 8. Շարժէ՛ սահեցուցիչները — ա՛յս է ապրող թարմացումը

Քաշէ՛ `PerimeterOffset` սահեցուցիչը։ Ներբանը ամէն անգամ կը նորոգուի։

Փորձէ՛.
- `PerimeterOffset` 2-էն 5՝ ներբանը ներս կը փոքրանայ։
- `ToeExtension` 10՝ ոտքի մատի կողմը կ՚երկարի։
- `BaseThk` 10՝ ներբանը կը հաստնայ։

Այսքա՛ն է ապրող թարմացման աշխատաձեւը։

## 9. Տեսանելի դարձնէ՛ կորագիծերը

Վերի ու տակի եզրային կորագիծերը տեսնելու համար.
1. Params → Geometry-էն գցէ՛ երկու `Curve` պարամետր։
2. Կապէ՛ `TopEdge` → առաջինին, `BottomEdge` → երկրորդին։
3. Երկու կորագիծերն ալ Rhino-ին մէջ կ՚երեւին՝ ներբանին եզրը հետեւելով։

## 10. Խմբագրէ՛ ստուգման կէտերը (control points) — «քաշելով ձեւ տալու» աշխատաձեւը

Այս է մեծ առաւելութիւնը .rhi հաւելումէն։

1. Աջ-սեղմէ՛ **TopEdge Curve պարամետրին** → **Bake**։
   - Շերտի (layer) մասին հարցում կը բացուի։ Լռելեանը ընդունէ՛, OK։
   - Կորագիծը հիմա Rhino-ի փաստաթուղթին մէջ իսկական առարկայ մըն է։
2. **Rhino**-ին մէջ ընտրէ՛ կորագիծը ու բացի՛ր ստուգման կէտերը։
   Հրահանգագիծին գրէ՛ `PointsOn` (կամ՝ F10)։
3. Քաշէ՛ կէտերը ուր որ ուզես։ Ամէն քաշուածք կորագիծը կը փոխէ։
4. **Grasshopper**-ին մէջ Params → Geometry-էն գցէ՛ `Curve` պարամետր
   մը։ Աջ-սեղմէ՛ → **Set one Curve** → Rhino-ին մէջ ընտրէ՛ քու
   խմբագրած կորագիծը։
5. Կապէ՛ այս Curve պարամետրը ծրագիրի `OverrideOutline` մուտքին։
6. Ներբանը կը նորոգուի՝ քու քաշած ձեւով։ Սահեցուցիչները տակաւին
   կ՚աշխատին, բայց `PerimeterOffset` / `ToeExtension` / `HeelExtension`
   հիմա անտեսուած են — ձեռովի ուրուագիծդ կ՚առաջնահերթուի։

Նոյնը՝ `BottomEdge` → `OverrideBottom`-ի համար, եթէ տակը կ՚ուզես ձեւել։

Ինքնագործ ուրուագիծին վերադառնալու համար. աջ-սեղմէ՛ Curve
պարամետրին, որ կը կապուի `OverrideOutline`-ին → **Disconnect**
անջատէ՛ լարը։

---

## 11. Պահէ՛ սահմանումը

1. Grasshopper-ին մէջ՝ **File → Save As** → անունը՝ `OrthoticInsole.gh`։
2. Յաջորդ անգամ. բացի՛ր Rhino-ն կաղապարովդ, յետոյ Grasshopper-ին
   մէջ՝ **File → Open** → ընտրէ՛ .gh ֆայլը։ Սահեցուցիչներու արժէքները
   ու Last-ի անդրադարձումը ֆայլին հետ կը պահուին։

---

## 12. Bake ընէ՛ վերջնական ներբանը Rhino-ի փաստաթուղթին

Երբ ձեւէն գոհ ես.
1. Աջ-սեղմէ՛ ծրագիրի **SubD** ելքը → **Bake**։
2. Շերտ ընտրէ՛, OK։
3. SubD-ն Rhino-ի մնայուն առարկայ մը կը դառնայ — կրնաս արտածել,
   mesh-ի վերածել, 3D տպել կամ յետագայ մշակում ընել։
4. Նոյնը՝ `TopEdge`, `BottomEdge`, `Footprint`, `Outline`-ի համար,
   եթէ զանոնք ալ կ՚ուզես պահել։

## Յաճախակի հանդիպող դժուարութիւններ

**«Ծրագիրի բաղադրիչը կարմիր է»**
- Hover ընէ՛։ Կարդա՛ սխալի հաղորդագրութիւնը։
- Ամէնէն յաճախ՝ պարտադիր մուտք մը անկապ է կամ սխալ տիպի։
  Ստուգէ՛ լարերդ։

**«Ներբանը գլխիվայր է / սխալ չափի է»**
- Կաղապարին ներբանը պէտք է −Z (վար) ուղղուած ըլլայ։ Անդրադարձելէ
  առաջ Rhino-ին մէջ դարձուր։

**«Ներբանը չի՛ երեւիր — միայն ուրուագիծը կ՚երեւի»**
- Հաւանաբար `Last` չէ կապուած կամ Brep պարամետրը կորսնցուցած է
  իր անդրադարձումը։ Աջ-սեղմէ՛ Brep պարամետրին → "Set one Brep" նորէն։

**«Սահեցուցիչները ապրող կերպով չեն թարմացներ»**
- Solver ընտրացանկը ստուգէ՛ (GH պատուհանի վերը) → համոզուէ՛ որ
  **Disabled** վիճակին մէջ չէ (պատկերակը կարմիր գիծ չպէտք է ունենայ)։

**«Բաղադրիչը դեղին է, ազդարարութիւնով»**
- Դեղինը ազդարարութիւն է, սխալ չէ։ Hover ընելով մանրամասն կարդա՛։
  Շատ յաճախ՝ "no curves found in section X" — եթէ SubD ելքը կու գայ,
  սովորաբար անվնաս է։

## Ինչ կ՚ընէ ամէն ելք

- **SubD** — հարթ բաժանումային մակերես, վերջնական արդիւնքն է։
  Bake ըրէ՛։
- **Mesh** — SubD-ի վերածուելէն առաջ՝ ենթադիր mesh-ը։ Օգտակար՝ եթէ
  SubD-ի վերածումը ձախողի (ատ ատեն SubD-ն դատարկ կը մնայ եւ
  փոխարէնը mesh-ը bake կ՚ընես)։
- **Footprint** — կոշիկի կաղապարի հատումներէն ստացուած հարթ XY
  ուրուագիծ։
- **Outline** — ներբանի շեղուած եզր (նոյնպէս հարթ XY)։
- **TopEdge** — եռա-չափ NURBS կորագիծ՝ վերի ներբան-հետեւող մասով։
- **BottomEdge** — եռա-չափ NURBS կորագիծ՝ տակի հարթ կողմով։
- **Axis** — `"X"` կամ `"Y"`, ուղղակի տեղեկատուական։
- **ToeDir** — `+1` կամ `-1`, ուղղակի տեղեկատուական։

## Խորհուրդ. պահէ՛ սահեցուցիչներու դրուածքները

Երբ կաղապարի մը համար յարմար արժէքներ կը գտնես.
1. Գրէ՛ սահեցուցիչներու արժէքները, ԿԱՄ
2. .gh ֆայլը պահէ՛ յատուկ անունով
   (օրինակ՝ `Mens_Size_10_Insole.gh`)։

Ամէն .gh ֆայլ՝ սահմանում մը գումարած սահեցուցիչներու վիճակ։
Կրնաս շատ ֆայլեր պահել՝ ամէն կաղապարի / յաճախորդի համար։
